# Обновление Svelte ASCII UI 0.1.0 → 0.2.0

9 ноября 2026. Ветка `codex/ascii-ui-020`; только preview до согласования.

## Основание

Проверены npm dist-tag latest (0.2.0), [релиз v0.2.0](https://github.com/IgorLo/svelte-ascii-ui/releases/tag/v0.2.0), установленный CHANGELOG, README, docs/agents/using.md, design-system.md, composition.md и публичные типы. Все шесть наших issues #5–10 закрыты в upstream. Важно: ниже различаются исправления библиотеки и их проверка в приложении.

## Изменения

- Пакет закреплён ровно на 0.2.0. Svelte 5.57.3 удовлетворяет peer requirement 5.57+.
- Включён штатный локальный Monocraft (300/400/600); удалены IBM Plex Mono и явные переопределения Theme.font. Проверены русские заголовки, длинные подписи и таблица.
- Подсказки факторов используют публичный `triggerVariant="compact"`, без собственной геометрии и trigger-snippet.
- Новые hover и заливки полей/primary-кнопок приходят из пакета. Убрана дублирующая заливка выбранных пунктов навигации; текстовый маркер и aria-pressed сохранены.
- Сравнение использует публичные иконки plus/minus. Кастомный знак отправки ссылки оставлен: подходящей share-иконки в текущем наборе нет.
- Компактные формы остаются S. Массово заменять M на L не понадобилось: новые размеры проверяются в реальных раскладках; размеры окна Drawer/Dialog — отдельный контракт.
- По composition guide качество фактора — измерение, поэтому Progress заменён на native meter. Нормализованная шкала 0–1 и её пороги 0.33/0.66 соответствуют уже существующим группам рейтинга. Подпись процента вклада сохранена отдельно. Нет данных — текст вместо нулевой шкалы. Native meter оформлен утилитами приложения в прежних семантических цветах, это не патч UIKit. Внешний вид в разных движках может различаться.
- Карта, палитра таблицы, веса, данные, расчёт рейтинга и URL не менялись.

## Визуальные и функциональные проверки

Основные экраны сняты при 1366×900 и 390×844. Горизонтального переполнения документа и pageerror в этих сценариях нет. Отдельно проверены hover, compact help, возврат фокуса, квадратная галочка с длинной подписью и touch-размеры. Используются публичные props; внутренних CSS-патчей пакета нет. Физический телефон и скринридер не проверялись.
