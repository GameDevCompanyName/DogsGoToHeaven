# Calm Sunset: пробная тема

Основа: [Calm Sunset, Paulina Riva / Lospec](https://lospec.com/palette-list/calm-sunset).
Исходные цвета: `#684971`, `#a06389`, `#cb7ca2`, `#e1aea4`, `#f9d8a1`, `#ffecb2`, `#fffcf1`.

UIKit 0.2.0 сохранён. Все семь ролей Theme.colors переопределены приложением; `palette="paper"` выбирает только светлый системный color-scheme. Персиково-персиковый фон `#f9e2c5` и сливовый акцент дополнены почти чёрным текстом. Текст статусов, заливки таблицы и маркеры карты используют отдельные зелёные, жёлтые и красные цвета, независимо от бренда. Badge получает цветное содержимое через публичный snippet; внутренних CSS-патчей UIKit нет.

В настройках оставлена одна шкала «Важность: 0–10», без процентной доли среди включённых факторов. Рейтинг и веса не пересчитывались по новой формуле. Проценты налогов и реального вклада в балл города сохранены: это другие величины.

## Проверка контраста

WCAG 2 contrast ratio, без округления до проверки порога. Текст: ориентир 4.5:1, значимые контуры: 3:1. Для полей учитывается фактическая заливка браузера, для таблицы — цвет каждой заливки. Это проверка выбранных экранов и состояний, не заявление о полном соответствии WCAG; APCA и физический телефон не проверялись.

| Пара                                                  | Контраст                |
| ----------------------------------------------------- | ----------------------- |
| Основной текст / персиковый фон                       | 14.75:1                 |
| Вторичный текст / персиковый фон                      | 6.49:1                  |
| Сливовый акцент / персиковый фон                      | 7.00:1                  |
| Видимый текст проверенных экранов, минимальная пара   | 4.91:1                  |
| Текст поля: default / hover / focus                   | 12.91 / 12.21 / 11.65:1 |
| Текст таблицы: зелёная / жёлтая / красная ячейка      | 10.27 / 11.04 / 7.79:1  |
| Контур default-кнопки с opacity 0.85 / фон            | 4.56:1                  |
| Контур маркера / вода и суша                          | 5.99 / 8.21:1           |
| Вторичные подписи карты / вода и суша                 | 5.94 / 8.14:1           |
| Вторичные подписи карты / самая тёмная подложка дорог | 4.63:1                  |

Жёлтая заливка маркера сама по себе не имеет 3:1 со светлой картой: различимость формы обеспечивает тёмный контур 1.5px; выбранная точка дополнительно увеличивается и получает контур 3px. Географические декоративные границы и подложки не обязаны иметь контраст интерактивного элемента. Значения таблицы остаются текстовыми; их интерпретация доступна также через title и подпись для скринридера.

Визуально проверены старт, список, настройки, таблица, сравнение и карточка города при 1366×900 и 390×844. Переполнения документа по горизонтали и ошибок JavaScript в этих сценариях не обнаружено. Прозрачные заливки контролов, фокус и hover сохранены штатными средствами UIKit.
