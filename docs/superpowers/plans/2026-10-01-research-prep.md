# Подготовка к исследованию по странам — план

Oct 1, 2026 · @Игорь, Claude

Подготовка части A из `docs/superpowers/specs/2026-10-01-product-round-3-design.md`: код, реестр и бриф, чтобы агенты-исследователи могли писать обзоры `remote-tax`, `banking-ease` и `nomad-visa`, а скрипт — превращать их в выборки. Сами обзоры и выборки — следующим шагом. Каждая задача — тест, код, `npm run verify`, коммит.

1. **План** в `docs/superpowers/plans`.
2. **Спеки обзоров.** `shared/lib/notes/specs.ts`: `NoteSpec` — разделы, минимум источников и строка значения в последнем разделе (регулярка и разбор). Спеки `legalization-ease` (пять разделов, «Оценка: N из 5», три источника), `remote-tax` («Ставка: N %», десятичная запятая), `banking-ease` («Оценка: N из 5»), `nomad-visa` («Виза: есть/нет» и «Минимальный доход: N $ в месяц» или «не требуется»), у трёх новых — два источника. `parseNote(raw, spec)` с полем `value`; вызов без spec — легализация с прежним полем `score`. Vitest на каждую спеку: порядок разделов, нет строки значения.
3. **Тест данных по спекам.** `data.test.ts` разбирает каждую папку `data/notes/<factorId>/` её спекой; папка без спеки — ошибка.
4. **Факторы.** Формат `percent` («≈ 12 %») в схеме и `formatValue`. В `factors.json` — `remote-tax`, `banking-ease`, `nomad-visa-income` без выборок; у `tax-burden` вес 2 и уточнённая подсказка.
5. **Скрипт `notes-to-samples.ts`.** Фактор → спека → выборка `<factorId>.claude-research-2026`; для `nomad-visa` две выборки: категориальная `nomad-visa.research-2026` и числовая `nomad-visa-income.claude-research-2026`. Чистая сборка выборки — в `shared/lib/notes`, с тестом; `legalization-ease.ts` — обёртка.
6. **Бриф `docs/collect-research.md`.** Одна пачка — пять стран, три обзора на страну; форматы, рубрика банков, правило расчёта налога, правило визы, источники, проверка и сдача. Обновить `docs/data.md` и `CLAUDE.md`.
7. **Интерфейс.** `factor-note.svelte` по конфигу `widgets/city-card/config/notes.ts`: «Легализация», «Налоги для удалёнщика», «Банки»; в шапке значение фактора через `formatValue`; без файла блок скрыт. В «Справке» строка визы кочевника с минимальным доходом.
