# MVP UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One-screen MVP: MapLibre map with score-coloured cities, ranked list, settings panel with presets and factor controls, and a city card with the score breakdown.

**Architecture:** `RankingState` (a runes class in `entities/ranking`) owns dataset, settings and selection and derives `rank()` results; widgets read it from Svelte context. Map sync is the only `$effect` user. FSD layers strictly top-down via `index.ts`.

**Tech Stack:** Svelte 5 runes, SvelteKit static, shadcn-svelte (Bits UI + Tailwind 4), MapLibre GL JS, OpenFreeMap tiles, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-28-mvp-ui-design.md`

## Global Constraints

- Svelte 5 runes only; `$effect` only in `widgets/city-map` with a comment why not `$derived`; no state mutation inside `$effect`.
- Script block order per `docs/code-style.md`: imports, types, `$props`, `$state`, `$derived`, functions, `$effect`.
- Callback props (`onselect`), snippets, `cn` for conditional classes, Tailwind only.
- Every `.svelte` and `.svelte.ts` file is validated with the Svelte MCP autofixer (`svelte:svelte-code-writer` skill) before commit.
- UI strings in Russian. Mobile layout first (375px), desktop ≥ 768px.
- `npm run verify` green before every commit; Steiger clean.

## Review Focus

1. Dataset with zero visible cities (all below coverage): list shows the hidden counter, map shows no circles, no crash. Test in Task 8 (e2e with fixture is out of scope; unit test on `RankingState` in Task 2 with an empty ranked set).
2. Slider moved to 0 with checkbox still on: factor drops out of contributions and the card must not show it. Covered by engine tests; UI test in Task 2 (`setWeight(id, 0)` removes it from `result`).
3. Selecting a preset after manual edits resets those edits (spec §5). Test in Task 2.
4. City selected, then filtered out by a new filter: card must close or show "скрыт фильтром". Rule: `selected` derives to `null` when the city is not in `ranked`; card closes. Test in Task 2.
5. MapLibre in Playwright/CI without WebGL: the e2e must assert on DOM (list, card), and only check that the map container exists; do not depend on tiles loading. Task 8.

**Interfaces (produces):**

  constructor(dataset: Dataset, presets: Preset[]);
  readonly dataset: Dataset;

  selectedCityId: CityId | null;

  readonly hiddenByFilter: number;
  readonly selected: RankedCityView | null;
  applyPresets(durationId: string | null, incomeId: string | null): void;
  setWeight(id, value): void;
  setEnabled(id, flag): void;

  setNumericFilter(id, filter: NumericFilter | null): void;
  setCategoryFilter(id, allowed: string[] | null): void;
  selectCity(id: CityId | null): void;
}
export function createRankingState(raw: RawData): RankingState; // buildDataset + defaults + presets long-term/remote
export function setRankingContext(state): void;
