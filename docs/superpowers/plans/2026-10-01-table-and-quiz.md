# Таблица с сортировкой и квиз — план

Oct 1, 2026 · Claude

Часть C спеки `2026-10-01-product-round-3-design.md`. Ветка `feat/table-and-quiz` от `develop`.

## Задачи

1. **Сортировка городов.** Чистая `sortCities(views, sort)` в `entities/ranking/lib/sort-cities.ts`: по числовому значению фактора, по возрастанию или убыванию, пропуски всегда в конце, при равенстве — порядок по баллу. Тесты рядом.
2. **Сортировка в состоянии и ссылке.** `RankingState.sort: { factorId; direction } | null`, `toggleSort(factorId)` по кругу «по возрастанию → по убыванию → по баллу», `tableCities` — выдача в порядке сортировки. `url-state` пишет и читает `sort=rent:asc`, неизвестный или категориальный фактор и мусор отбрасываются. Тесты на круг, ссылку и восстановление.
3. **Виджет `city-table`.** Колонки: место, город (липнет слева), страна, балл, все числовые факторы с данными в порядке реестра. Ячейка — `formatValue(...).primary` (у формата без числа — подпись уровня) на фоне тона уровня, уровень продублирован текстом для скринридера и в `title`. Заголовок — кнопка сортировки и подсказка фактора, `aria-sort` на `<th>`. Клик по строке и кнопка с названием города открывают карточку.
4. **Вкладка «Таблица» на главной.** Телефон: четвёртая кнопка в нижней панели, таблица во весь экран, как «Города». Десктоп: третья вкладка; таблица ложится поверх карты на всю правую часть (карта остаётся смонтированной), слева — настройки, чтобы двигать веса и сразу видеть таблицу. Playwright: сортировка по колонке на телефоне и десктопе.
5. **Логика квиза.** `features/quiz`: пять вопросов в `config`, чистая `quizToSettings(answers, presets)` в `lib`: сумма «весов ответа» → ближайшая персона по косинусу → поверх неё правки ответов (веса берутся по максимуму, фактор с весом включается). Тесты: каждый вариант каждого вопроса меняет результат, нейтральные ответы дают `remote-long`.
6. **Экран квиза.** `pages/quiz` + `routes/quiz`: вопрос на экран, прогресс, крупные кнопки, «Назад»; в конце флаг лендинга и переход на `/#…`, собранный `serializeState`. Ссылка «Не знаю, кто я — пройти опрос» на `/start`. Playwright: квиз доходит до карты с нажатой персоной и `p=` в адресе.

## Решения

- Сортировка только по числовым факторам: в таблице нет категориальных колонок. Колонки «место» и «балл» не сортируются кнопкой: третий клик по фактору и есть возврат к порядку по баллу, `aria-sort="descending"` у балла показывает его.
- Размер города в квизе — мягкий диапазон `population` с весом, а не жёсткий фильтр: фильтр по населению отсёк бы большую часть выдачи.
