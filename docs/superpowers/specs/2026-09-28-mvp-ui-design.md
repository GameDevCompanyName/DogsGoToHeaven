# MVP интерфейса — дизайн

Sep 28, 2026 · @Игорь, Claude

Закрывает пункты 4–6 роадмапа из `docs/prd.md`: карта с подсветкой, панель факторов и пресетов, карточка города. Опирается на движок из `2026-09-27-data-model-and-ranking-design.md`.

## Договорённости и решения

1. **Один экран.** Карта, список городов, настройки и карточка города живут на `/`. Никаких переходов между страницами.
2. **Телефон сначала.** На узком экране (< 768px) — карта во весь экран и нижняя панель-вкладки: «Карта», «Города», «Настройки». Активная вкладка «Города» или «Настройки» показывает панель поверх карты на всю высоту, «Карта» прячет её. На широком экране — левая колонка 400px с вкладками «Города» и «Настройки», карта справа всегда видна.
3. **Карточка города** — шторка снизу (`Sheet` из shadcn-svelte, `side="bottom"` на телефоне, `side="right"` на десктопе) поверх всего.
4. **Карта — MapLibre GL, тайлы OpenFreeMap** (`https://tiles.openfreemap.org/styles/positron`): открытые, без ключей и лимитов. Города — слой `circle` из GeoJSON, цвет по баллу через `interpolate`, отсечённые города серые, выбранный — обводка. Клик по кружку открывает карточку.
5. **Состояние** — один реактивный класс `RankingState` в `entities/ranking`, никаких сторов. Выбор пресета сбрасывает ручные правки: настройки = база из реестра + активные пресеты. Настройки в ссылке не сохраняются.
6. **Города без данных** не показываются ни в списке, ни на карте (`excluded` с причиной `coverage`); их число выводится под списком одной строкой: «Ещё N городов скрыты: мало данных».
7. **Источник и дата** у каждого числа в карточке: из `provenance`. Визовые факторы сопровождаются дисклеймером «справка, не юридическая консультация».

## `RankingState`

```ts
class RankingState {
  readonly dataset: Dataset;
  readonly presets: Preset[];
  durationPresetId = $state<string | null>(null);
  incomePresetId = $state<string | null>(null);
  settings = $state<RankingSettings>(...);   // база + пресеты, поверх — ручные правки
  selectedCityId = $state<CityId | null>(null);

  result = $derived(rank(this.dataset, this.settings));
  rankedCities = $derived(...);       // RankedCity + DatasetCity вместе, для списка и карты
  hiddenByCoverage = $derived(count);
  selected = $derived(...);           // город + RankedCity | null

  applyPresets(durationId, incomeId)  // пересобирает settings из базы
  setWeight(id, v) / setEnabled(id, b) / setRange(id, [a, b])
  setNumericFilter(id, { min?, max? } | null) / setCategoryFilter(id, allowed | null)
  selectCity(id | null)
}
```

Создаётся один раз в `HomePage` из `loadRawData()` и `buildDataset`, раздаётся вниз через `setContext`. Пресеты по умолчанию: `long-term` и `remote`.

## Панель настроек

Сверху два селекта: «Срок» (На месяц / Насовсем) и «Доход» (Удалённый / На месте). Ниже группы факторов в порядке реестра, каждая — заголовок и список факторов.

Числовой фактор: строка с галочкой и названием, ползунок 0–10 (неактивен, если галочка снята), под ним компактная строка порога: два поля «от» и «до» (для `range` — целевой диапазон вместо порога, с подписью «цель»). Категориальный фактор: название и набор чекбоксов по категориям; все сняты — фильтра нет.

Пересчёт при каждом движении ползунка, без кнопки «Применить».

## Список городов

Строка: ранг, название, страна, балл 0–100 (округлённый `score × 100`), метка «нет данных по N факторам», если `missingFactorIds` не пуст. Клик — выбор города и открытие карточки. Под списком счётчик скрытых по покрытию и по фильтрам.

## Карточка города

Заголовок: название, страна, ранг и балл. Список активных факторов, отсортированный по вкладу: название, значение с единицей (или «нет данных»), полоска нормализованной оценки 0–1, доля вклада в процентах. Под каждым — источник и период мелким шрифтом. Категориальные факторы — отдельным блоком «Справка»: значение словами и дисклеймер.

## Карта

`$effect` только для синхронизации с MapLibre (создание карты, обновление источника GeoJSON при смене `rankedCities`, подсветка выбранного). Каждый `$effect` с комментарием, почему не `$derived`. Цвет: `interpolate` по `score` от красного (0) через жёлтый (0.5) к зелёному (1), отсечённые фильтром — серые, по покрытию — не рисуются. При выборе города карта плавно центрируется на нём (`flyTo`), масштаб не меняется.

## Тесты

- Vitest: `RankingState` — выбор пресета пересобирает настройки, ручная правка веса меняет `result`, `selectCity`. Тест на выдуманном датасете из фикстуры.
- Playwright (`tests/e2e`): карта рендерится (есть canvas и хотя бы один город в списке), движение ползунка меняет первый город в списке или его балл, клик по городу открывает карточку с разбором. Прогон на реальных данных из `data/`.

## Вне задачи

- Сохранение настроек в ссылке, поиск по городам, кластеризация на карте, тёмная тема, аналитика.
