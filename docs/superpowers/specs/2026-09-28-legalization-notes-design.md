# Обзоры легализации и фактор «Лёгкость легализации» — дизайн

Sep 28, 2026 · @Игорь, Claude

Дополнение к `2026-09-27-data-collection-design.md`. Заказано владельцем: по каждой стране обзор легализации для граждан РФ и оценка 1–5, которую можно учитывать в ранжировании.

## Договорённости

1. **Это единственное место, где оценку даёт модель.** Агент-исследователь читает свежие источники по стране и формирует вердикт по рубрике. В `source.name` выборки так и записано: «Оценка Claude по открытым источникам». Все остальные факторы по-прежнему только из источников.
2. **Оценка — обычный числовой фактор** `legalization-ease` уровня страны, группа «Легализация», «больше лучше», шкала 1–5, вес по умолчанию 6. Движок не меняется.
3. **Обзор — отдельный Markdown-файл на страну**, `data/notes/legalization/<countryId>.md`, около пяти абзацев. В бандл не попадает целиком: интерфейс подгружает файл по требованию при открытии карточки города этой страны.
4. **Единая структура обзора**, чтобы страны были сравнимы. Пять блоков в фиксированном порядке (заголовки второго уровня):
   1. **Въезд** — визовый режим, срок пребывания, известные ограничения на въезд.
   2. **Пути к ВНЖ** — какие основания реально доступны гражданам РФ сейчас: удалённая работа или виза кочевника, работа по найму, учёба, предпринимательство, инвестиции, воссоединение, «по факту проживания».
   3. **ПМЖ и гражданство** — сроки, требования к языку и доходу, допускается ли второе гражданство.
   4. **Подводные камни** — банки и платежи, санкционные ограничения, практика ведомств, отношение к россиянам, размер русскоязычного сообщества.
   5. **Вердикт** — одно-два предложения и строка «Оценка: N из 5».
5. **Рубрика 1–5** с якорями, чтобы разные агенты ставили оценки одинаково:
   - **5** — безвизовый въезд на длительный срок и хотя бы один простой путь к ВНЖ без работодателя и крупных вложений (пример: Грузия, Армения, Сербия, Казахстан).
   - **4** — въезд без визы или по простой визе, есть доступный путь к ВНЖ с умеренными требованиями: виза кочевника, ИП, учёба (пример: Черногория, Турция, Таиланд, Аргентина).
   - **3** — нужна консульская виза или ВНЖ требует работодателя, вложений или высокого подтверждённого дохода, но путь рабочий и россиянам открыт (пример: Испания, Португалия, ОАЭ, Кипр).
   - **2** — виза выдаётся с трудом, пути к ВНЖ узкие, есть ограничения именно для граждан РФ: банки, отказы, приостановленные программы (пример: Германия, Нидерланды, США).
   - **1** — въезд по туристической визе закрыт или ВНЖ для граждан РФ практически недоступен (пример: Латвия, Эстония, Польша, Чехия, Финляндия).
6. **Калибровка.** После всех пачек один агент читает все 69 вердиктов и оценок разом и выравнивает выбросы, правя только строку «Оценка» и выборку, не переписывая обзоры.

## Формат файла обзора

```markdown
---
countryId: ge
checkedAt: 2026-09-28
sources:
  - https://www.geoconsul.gov.ge/...
  - https://...
---

## Въезд

...

## Пути к ВНЖ

...

## ПМЖ и гражданство

...

## Подводные камни

...

## Вердикт

... Оценка: 5 из 5.
```

- Шапка YAML: `countryId` совпадает с именем файла, `checkedAt` — дата проверки, `sources` — минимум три ссылки на первоисточники или крупные СМИ, не блоги визовых агентств.
- Текст на русском, без обращения к читателю, без «мы», без маркетинга.
- Дисклеймер не пишется в каждом файле: интерфейс показывает его один раз над обзором.

## Выборка оценок

`data/samples/legalization-ease.claude-research-2026.json`, обычный формат: `values` — числа 1–5 по странам, `source.name` — «Оценка Claude по открытым источникам», `notes` — ссылка на рубрику в этой спеке. `activeSample` проставляется после калибровки.

## Код

- Схема: `data/notes/<factorId>/<key>.md` — общий механизм «заметка к значению фактора», не только для легализации. Загрузчик `shared/api/dataset` отдаёт `loadNote(factorId, key): Promise<Note | null>` через ленивый `import.meta.glob` с `query: '?raw'`; парсинг шапки — маленькая функция без зависимостей, тело — Markdown, который интерфейс рендерит простым способом (заголовки, абзацы, списки).
- Тест данных: каждый файл заметки лежит в папке существующего фактора, имя файла — существующий ключ уровня фактора, шапка полная, дата валидна, источников не меньше трёх.
- Интерфейс: в карточке города блок «Легализация в <страна>» с оценкой, датой проверки, дисклеймером и обзором, раскрывается по тапу.

## Сбор

Отдельный бриф `docs/collect-legalization.md`: рубрика, структура, правила поиска (официальные сайты ведомств, консульства, крупные СМИ, свежесть не старше года там, где возможно), запрет на копирование текста источников, объём. Один агент — пачка из десяти стран, ветка `notes/legalization-<n>`. Агенты пишут обзоры и предварительные оценки; калибровочный агент собирает выборку и выравнивает.

## Вне задачи

- Обзоры по городам.
- Автоматическое обновление обзоров.
