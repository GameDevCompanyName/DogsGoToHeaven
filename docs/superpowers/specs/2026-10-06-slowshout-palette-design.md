# Палитра slowshout16 и шрифт PT Mono

Запрос владельца: перевести сайт целиком на палитру [slowshout16](https://lospec.com/palette-list/slowshout16) (16 цветов, автор Phenomenician) и шрифт [PT Mono](https://fonts.google.com/specimen/PT+Mono), включая карту и компоненты shadcn. Где какой цвет — решение за нами, главное читаемость.

## Где живут цвета

- `src/app/styles/app.css` — единственное место с hex: 16 цветов палитры под своими именами (`--color-ink`, `--color-paper`, `--color-moss`…) и семантические токены shadcn поверх них.
- `src/shared/lib/tone` — тона «хорошо / терпимо / плохо / нейтрально» классами Tailwind и те же цвета в hex для MapLibre (`TONE_HEX`, `PALETTE_HEX`).
- `src/widgets/city-map/lib/recolor-style.ts` — перекраска стиля Positron: карта забирает JSON стиля сама и получает его уже в палитре (`transformStyle` в MapLibre 6.11 есть только у `setStyle`). Слои узнаются по id и типу свойства.

Фон — бумага `#faefd9`: кремовый из палитры (`#eedebe`) на весь экран показался владельцу слишком жёлтым, он остался для вторичных поверхностей. Светлые заливки — цвет палитры с прозрачностью поверх бумаги (`bg-moss/20`, на карте — явное смешение с бумагой). Других оттенков нет.

## Решения

| Роль                       | Цвет                                                                   | Контраст с парой                   |
| -------------------------- | ---------------------------------------------------------------------- | ---------------------------------- |
| Фон, карточки, попапы      | paper `#faefd9`                                                        | —                                  |
| Текст                      | ink `#23222f`                                                          | 13.7 на бумаге                     |
| Вторичный текст            | plum `#52485f`                                                         | 7.5 на бумаге, 6.5 на cream        |
| Primary (кнопки, активное) | slate `#4e5d79`, текст paper                                           | 5.8                                |
| Secondary, muted, accent   | cream `#eedebe`, текст ink                                             | 11.8                               |
| Границы, инпуты            | sand `#b9b595`                                                         | —                                  |
| Фокус (ring)               | steel `#638691`                                                        | —                                  |
| Destructive                | rust `#754242`                                                         | 7.0 на бумаге                      |
| Тон «хорошо»               | полоса moss `#6a7d5f`, текст teal `#485a5c`                            | 6.4 на бумаге, 5.4 на заливке 15 % |
| Тон «терпимо»              | полоса gold `#cf982e`, текст bark `#544a36`                            | 7.6 на бумаге, 6.6 на заливке 20 % |
| Тон «плохо»                | полоса brick `#a75141`, текст rust `#754242`                           | 7.0 на бумаге, 5.8 на заливке 15 % |
| Нейтральный тон            | полоса ash `#8e9593`, текст plum                                       | 6.5 на cream                       |
| Бейдж балла (5 ступеней)   | moss 45 % → moss 20 % → gold 25 % → brick 20 % → brick 45 %, число ink | не ниже 7.3                        |

Сами тона (moss, gold, brick) для текста слишком светлые (3.9, 2.2, 4.7 на бумаге), поэтому текст тона — его тёмный сосед по палитре. Цвет всегда идёт вместе с текстом, так что оттенок соседа читается как тот же тон.

### Карта

Фон, ледники и пирсы — paper; вода — steel 60 %; парки — moss 25 %, леса — moss 35 %; застройка и жильё — sand 35 %; обводки дорог и рельсы — sand, полотно — paper, второстепенные дороги — sand 55 %; границы — ash. Подписи городов — ink, воды — slate, остальные — plum, ореол у всех — paper. Маркеры городов — `TONE_HEX`, обводка paper, у выбранного — ink.

Шрифт подписей на карте остаётся Noto Sans: глифы отдаёт сервер тайлов, PT Mono там нет.

### Шрифт

`@fontsource/pt-mono` (одно начертание 400, кириллица и латиница), `--font-sans: 'PT Mono', ui-monospace, monospace`. Жирный браузер синтезирует. Размеры текста не меняем: моноширинный шрифт шире, но 16px на телефоне остаётся читаемым.
