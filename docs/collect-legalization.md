# Бриф исследователя легализации

Sep 28, 2026 · @Игорь, Claude

Самодостаточная инструкция для агента, который пишет **обзоры легализации для граждан РФ по пачке стран** и ставит предварительную оценку 1–5. Дизайн и рубрика — в `docs/superpowers/specs/2026-09-28-legalization-notes-design.md`, формат файлов — ниже. Общие правила репозитория — `CLAUDE.md`.

## Что делать

Тебе выдан список стран (id ISO и русское название). Для каждой страны:

1. Найди свежие первоисточники: сайт миграционного ведомства или МИД страны, консульство, официальные страницы визовых программ, крупные СМИ и юридические обзоры не старше года, где это возможно. Блоги визовых агентств и маркетинговые страницы — не источник.
2. Напиши обзор `data/notes/legalization/<countryId>.md` по структуре ниже. Около пяти абзацев, по одному на блок. Кратко, конкретно, с цифрами: сроки, суммы, требования. Своими словами, без копирования текста источников. На русском, без обращения к читателю.
3. Поставь предварительную оценку по рубрике и запиши её в блок «Вердикт» строкой «Оценка: N из 5».
4. Не читай в контекст лишнего: страницы источников бери через выдержки, а не целиком; не открывай чужие обзоры.

## Структура файла

```markdown
---
countryId: ge
checkedAt: 2026-09-28
sources:
  - https://...
  - https://...
  - https://...
---

## Въезд

Визовый режим для граждан РФ, срок пребывания, ограничения на въезд, если есть.

## Пути к ВНЖ

Какие основания реально доступны сейчас: удалённая работа или виза кочевника, работа по найму, учёба, предпринимательство, инвестиции, воссоединение семьи, ВНЖ по факту проживания. Требования к доходу и документам.

## ПМЖ и гражданство

Сроки до ПМЖ и гражданства, экзамены по языку, требования к доходу, допускается ли второе гражданство.

## Подводные камни

Банки и переводы, санкционные ограничения, практика отказов, отношение ведомств, размер русскоязычного сообщества.

## Вердикт

Одно-два предложения. Оценка: N из 5.
```

- `countryId` совпадает с именем файла.
- `sources` — не меньше трёх ссылок, только те, что реально использованы.
- Заголовки ровно эти пять, в этом порядке.

## Рубрика оценки

| Оценка | Критерий                                                                                                                              | Ориентиры                                 |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| 5      | Безвизовый въезд на длительный срок и хотя бы один простой путь к ВНЖ без работодателя и крупных вложений                             | Грузия, Армения, Сербия, Казахстан        |
| 4      | Въезд без визы или по простой визе; доступный путь к ВНЖ с умеренными требованиями: виза кочевника, ИП, учёба                         | Черногория, Турция, Таиланд, Аргентина    |
| 3      | Нужна консульская виза или ВНЖ требует работодателя, вложений или высокого подтверждённого дохода, но путь рабочий и россиянам открыт | Испания, Португалия, ОАЭ, Кипр            |
| 2      | Визы выдаются с трудом, пути к ВНЖ узкие, есть ограничения именно для граждан РФ: банки, отказы, приостановленные программы           | Германия, Нидерланды, США                 |
| 1      | Въезд по туристической визе закрыт или ВНЖ для граждан РФ практически недоступен                                                      | Латвия, Эстония, Польша, Чехия, Финляндия |

Ориентиры — не готовые ответы: если источники показывают, что ситуация изменилась, ставь по критерию, а не по ориентиру, и объясни в вердикте.

## Проверка и сдача

1. `npm run test` — тест данных проверяет шапку, заголовки, число источников и существование страны.
2. Ветка `notes/legalization-<номер пачки>`, коммит `data(notes): add legalization notes batch <n>`, пуш. Пул-реквест не открывать.
3. Отчёт: список стран с оценками одной строкой на страну; страны, по которым источников не хватило и почему; сколько заняла пачка.
