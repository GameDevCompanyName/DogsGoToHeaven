# CLAUDE.md

«Все псы попадают в рай» — сервис выбора города для переезда. SvelteKit со статическим адаптером, без бэкенда, ранжирование считается в браузере.

- Что строим: `docs/prd.md`
- Как пишем код: `docs/code-style.md` — прочитай перед любой задачей и следуй ему строго.
- Формат данных: `docs/data.md`. Бриф для агента-сборщика одной выборки: `docs/collect.md`. Бриф для обзоров легализации: `docs/collect-legalization.md`.

## Команды

```bash
npm run dev        # дев-сервер
npm run lint       # Prettier --check, ESLint, Steiger
npm run check      # svelte-check
npm run test       # Vitest
npm run test:e2e   # Playwright
npm run data:report # покрытие датасета по факторам
npm run verify     # всё вышеперечисленное разом
```

## Жёсткие правила

1. Перед каждым коммитом и в конце каждой задачи — `npm run verify`. Задача не готова, пока он не зелёный. Все ошибки и предупреждения исправляешь сам.
2. Никогда не пушить в `main` и `develop`. Одна фича — одна ветка от `develop`, результат — пул-реквест в `develop` с описанием: что сделано, почему так, как проверить. `main` — только релизы: пул-реквест `develop → main` открывается по запросу Игоря, после мержа Vercel сам выкатывает продакшен. Фичи в `develop` мержатся squash, релиз в `main` — merge-коммитом, после релиза `develop` подтягивается к `main` fast-forward.
3. Коммиты — Conventional Commits на английском.
4. Архитектура — FSD. Импорт только из слоёв ниже, только через `index.ts` слайса. Steiger должен быть чистым.
5. Svelte 5 — только руны. `$effect` только с комментарием, почему не `$derived`.
6. Движок ранжирования в `shared/lib/ranking` — чистый TypeScript без Svelte. Любое изменение в нём — с тестами.
7. Данные лежат в `data/` вне `src` и проверяются тестом `data.test.ts`: реестр факторов, пресеты, города и выборки — это JSON, а не код.
8. Тесты — только на бизнес-логику и ключевые сценарии. Тесты ради покрытия не пишем.
9. Интерфейс на русском, вёрстка сначала под телефон.
10. Если правило из `docs/code-style.md` мешает задаче — не обходи его молча, спроси.
